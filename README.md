# Uzay Gezgini

Tarayıcıda çalışan 3D uzay gezgini (Vite + TypeScript + Three.js).

## Çalıştırma

```bash
npm install
npm run dev
```

## Yayınlama (Vercel)

Depoyu GitHub'a gönderip vercel.com'da "Import Project" ile seçin; Vite otomatik algılanır
(build: `npm run build`, çıktı: `dist`).

## Kaynaklar

- Gezegen değerleri: NASA Planetary Fact Sheet, JPL "Approximate Positions of the Planets" (J2000 ortalama boylamları)
